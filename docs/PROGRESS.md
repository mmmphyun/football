## 7단계 세부 구현 내역 (Issue #89)
- **`formation.py`**:
  - 하드코딩 앵커 블렌딩(`0.7*raw + 0.3*anchor`) 및 인위적 $dx$ 오프셋 전면 제거.
  - 100% 실측 이벤트 평균 위치 산출 및 14대 표준 전술 역할(`tactical_role`, `tactical_role_ko`, `tactical_role_desc`) 도출.
  - 적응형 X축 클러스터링 기반 포메이션 대형(`_infer_shape_string`) 개선.
- **`playbook.py`**:
  - `possession` ID 기반 체인 분할 및 패스 실패 시 조기 종료.
  - 컷백(음의 패스 $End X \le Start X$), 포켓 3자 침투($4.0$초 윈도우), 딥 라인브레이킹, 하프스페이스 언더랩, 압박속공 슛 정밀 분류.
  - 가짜 더미 궤적 주입 로직 제거.
- **`pressure.py`**:
  - StatsBomb 표준 PPDA(상대 $x \le 48\text{m}$ 패스 / 수비 $x \ge 48\text{m}$ 수비액션) 공식 적용.
  - 실측 3초 다인 압박 핫스팟 클러스터링 유지 및 더미 제거.
- **`zones.py`**:
  - 12x8 피치 구역 점유율 정규화 및 샘플 무결성 유지.
